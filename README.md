# Lampa Anime Filler

Плагин Lampa с цветными метками классификации эпизодов. Текущая тестовая ветка `kodik-test` предназначена только для сценария **Online_Mod → Kodik** на LG webOS. Плагин не меняет воспроизведение и не пропускает эпизоды автоматически.

## Тестовая установка

В Lampa откройте **Настройки → Расширения / Плагины → Добавить плагин** и укажите:

```text
https://cdn.jsdelivr.net/gh/nMagic/lampa-anime-filler@kodik-test/install-kodik8.js
```

Затем полностью перезапустите Lampa. Стабильный адрес `https://nmagic.github.io/lampa-anime-filler/a.js` этой веткой не изменяется.

## Что исправлено в 0.5.0-kodik.8

- Исследован актуальный Online_Mod, commit `cde2cf057e6634df43553fe8deeaef5030f95945`.
- Kodik сначала определяется Online_Mod по Shikimori, WorldArt, Kinopoisk, IMDb или внутреннему ID. В список передаются реальные `season`, `episode` и оригинальное название выбранной записи Kodik.
- Плагин сохраняет эти поля при вызове `Lampa.Template.get('online_mod', element)` и преобразует их в абсолютный номер каталога.
- Для частей одного сезона используется точное оригинальное название Kodik. Если оно неоднозначно, метка не ставится.
- При смене сезона или озвучки новые строки маркируются заново; старые метки не копируются между карточками.
- Плашка на карточке показывается только после точного сопоставления с каталогом; для отсутствующих произведений причина остаётся только в диагностике.
- Ограничение в 1000 DOM-строк удалено: поздние эпизоды длинных сериалов обрабатываются полностью.
- Диагностика отдельно показывает строки текущего списка, успешные метки, эпизоды без классификации и неизвестные соответствия.

## Покрытие каталога

В каталоге 45 произведений и 9552 классифицированных эпизода. Snapshot Kodik от 30.10.2026 содержит явный результат для каждой записи:

- 34 произведения — проверенное полное преобразование;
- 10 — частичное преобразование (маркируется только доказанный диапазон);
- 1 — произведение не найдено в Kodik;
- 9129 из 9552 эпизодов имеют проверенное преобразование Kodik, 423 намеренно остаются без угадывания.

Конкретный статус каждого произведения хранится в [`data/kodik.v1.json`](data/kodik.v1.json). `partial` не блокирует уже проверенные сезоны и эпизоды.

## Проверка на LG webOS

### Bleach

1. Открыть **Bleach / Блич**.
2. Выбрать **Online_Mod → Kodik**, первый сериал (`Bleach`, сезон 1).
3. Проверить: 1 — Canon, 33 — Filler, 64 — Filler, 168 — Filler, 228 — Filler, 366 — Canon.
4. Ожидается маркировка доступных эпизодов 1–366. Продолжения за пределами проверенного Kodik-диапазона не должны получать случайные метки.

### Naruto / Naruto Shippuden

1. Открыть каждую карточку отдельно.
2. В Naruto проверить: 1 — Canon, 136 — Filler, 220 — Mixed. В Shippuden: 1 — Mixed, 221 — Canon, 500 — Canon.
3. Сменить озвучку и вернуться назад. Номера и типы меток должны сохраниться.

### My Hero Academia

1. Открыть **My Hero Academia / Моя геройская академия**.
2. Переключить сезоны 1, 3 и 6.
3. Проверить S1E1 → абсолютный 1 — Canon, S3E1 → 39 — Filler, S6E25 → 138 — Canon.
4. Вернуться в предыдущий сезон: метки должны появиться снова без дублирования.

### One Piece

1. Открыть **One Piece / Ван-Пис** через Kodik.
2. Проверить: 54 — Filler, 55 — Filler, 1077 — Canon, 1173 — Canon (если эти номера есть в выбранной озвучке).
3. Kodik отдаёт этому произведению уже абсолютные номера; метка должна соответствовать тому же номеру.

При ошибке откройте **Настройки → Anime Filler → Показать диагностику**. Нужны строки «Карточка», «Kodik-строк распознано», «Система нумерации», «Покрытие произведения Kodik», «Меток проставлено», «Без классификации», «Неизвестное соответствие» и «Ошибка».

## Категории

- красная `Ф · Филлер`;
- жёлтая `С · Канон + филлер`;
- зелёная `М · Манга-канон` или `К · Канон`;
- синяя `А · Аниме-канон`.

## Тесты

```bash
node --check lampa-anime-filler.js
node --check a.js
node --test tests/*.cjs tests/*.mjs
node scripts/build-data.mjs --verify data/generated/v1
```

Тесты охватывают все 45 записей каталога, реальные правила Kodik для Bleach, One Piece и My Hero Academia, сезонные части, смену строк интерфейса, отсутствие дублей и список длиннее 1000 эпизодов. Автотесты не заменяют проверку на телевизоре.
